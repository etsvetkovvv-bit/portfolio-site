# Егор Цветков — сайт

Лендинг для Instagram-био: обучение нейросетям и проекты на заказ.

## Что внутри

- **`index.html`** — весь сайт в одном файле (HTML + CSS + JS, без зависимостей и сборки).
- 3 языка: **RU / EN / ES** с переключателем в правом верхнем углу. Цена автоматически меняется: `10 000 ₽` → `€100`.
- Стиль в духе Apple: светлый минимализм, плавные анимации появления, движущиеся элементы.
- Секции: hero, бренды (бегущая строка), о себе, обучение + оффер, заказы, FAQ, финальный призыв, футер.

## Как опубликовать на своём домене

Сайт — статический, поэтому подойдёт любой хостинг:

1. **Свой хостинг / домен:** загрузи `index.html` в корень сайта (рядом с папкой публикации). Готово.
2. **GitHub Pages:** в настройках репозитория → *Pages* → выбери ветку и папку `/ (root)`.
3. **Netlify / Vercel:** просто перетащи файл `index.html` в их интерфейс деплоя.

## Что можно поменять самому

- **Ссылки** — Telegram (`https://t.me/etsvetkovvv`) и Instagram (`https://www.instagram.com/tsvetkovvv.ai/`) находятся в атрибутах `href`.
- **Тексты** — все надписи лежат в объекте `I18N` внутри `<script>` (по языкам `ru` / `en` / `es`).
- **Цена** — ключ `learn.price` в каждом языке.
- **Превью ссылки** (для Telegram/соцсетей) — можно добавить свою картинку в `<meta property="og:image" ...>` в `<head>`.
